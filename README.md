🏦 Banking Analysis Project

1. Project Overview

The Banking Analysis Project focuses on analyzing banking and loan-related data to understand loan performance, repayment behavior, financial performance, customer/loan trends, and monthly disbursement patterns.

The project was completed using four data analytics modules: Excel, SQL, Power BI, and Tableau.

The complete workflow included:

Data Cleaning → Data Analysis → SQL Queries → Data Visualization → Dashboard Creation → Business Insights

⸻

4. Module 3 — Power BI

This is the main dashboard module shown in your screenshot.

🔹 What I used Power BI for

Power BI was used to create an interactive Banking Analysis Dashboard.

The dashboard combines KPIs and different charts to provide an overall view of banking and loan performance.

🔹 KPIs Used

From your dashboard screenshot, the main KPIs are:

1. On-Time Repayment % — 71.05%
2. Total Funded Amount — $2.36M
3. Principal Recovery Rate — 99.05%
4. Interest Income — $5.06M
5. Average Loan Size — $26.18K
6. Default Rate — 5.00%

These KPIs give a quick overview of the financial and repayment performance.

🔹 Visuals Used

Your dashboard contains several different visualizations.

1. Loan Growth by Grade

This visual shows the distribution/performance of loans according to loan grades such as:

* A
* B
* C
* D
* E

It helps compare loan amounts/performance across different grades.

2. State-Wise Performance

This chart compares loan/financial performance across different states.

It helps identify states contributing different levels of loan activity.

3. Total Loan Amount Disbursed

This visual shows the amount of loans disbursed across different categories/statuses.

4. Loan Status Distribution

This chart shows different loan statuses such as:

* Active

5. Product Profitability

This visualization compares different products based on:
